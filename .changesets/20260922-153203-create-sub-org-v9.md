Introduces `CreateSubOrganizationV9`. Root users are `RootUserParamsV6` (V5 plus `walletAuthenticators`):

```json
{
  "userName": "alice",
  "apiKeys": [],
  "authenticators": [],
  "oauthProviders": [],
  "walletAuthenticators": [
    {
      "type": "WALLET_AUTHENTICATOR_TYPE_ETHEREUM",
      "address": "0x71c7656ec7ab88b098defb751b7401b5f6d8976f",
      "domain": "app.example.com"
    }
  ]
}
```

> `walletAuthenticators` is required. Send `[]` when unused.
> Only Ethereum (`WALLET_AUTHENTICATOR_TYPE_ETHEREUM`) and Solana (`WALLET_AUTHENTICATOR_TYPE_SOLANA`) are accepted as `walletAuthenticators`.
> OTP signup client signatures must be signed as `signupV3` while using this new create suborg version.

This is a **breaking** major bump, please revise your create sub org implementation to add the new required `walletAuthenticators` array if moving onto this
version
